| 分支 | 内容 | 标签 |
|---|---|---|
| 目的 [G1] | 表面"多找买家" → 真实意图：降低对少数老客户的依赖 | 推断 |
| 第一性原理 [F1] | 买家要稳定品质、准时交付、合理价格；买家也在主动找工厂。站不住的假设："新客户只能靠展会" | 事实 / 推断 |
| 限制 [L1] | 无自有品牌；首年预算有限 | 事实 / 假设 |
| 成功标准 [S1] | 12 个月内新渠道订单占比 20% | 事实 |
| 可用资源 [R1] | 出口资质；负责人常驻英国 | 事实 |
